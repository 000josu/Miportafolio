Cosas importantes para programar

Para empezar a programar necesitamos unos elementos que son importantes para elaborar codigos

Variables

Una variable es espacio en la memoria que guarda un dato que puede cambiar en cualquer momento nuestro codigo. Para crear una variable se utiliza "let" y luego el nombre de tu variable por ejm: let nombre. Y para inicializar la variable se necesita crear la variable (let nombre) y poner el valor q le vamos a dar para inicializarla, por ejm: let nombre = 1

Tipos de datos

Los tipos de datos son las categorias q utlilzan los lenguajes de programacion para clasificar informacion que se guarda en las variables, algunos tipos de datos son:
- String (texto) : es el que se representa cuando hay texto y se identifica cuando hay "" alrededor de la variable, por ejm: let nombre = "Josue"
- Number (numero) : es el que representa numeros asi sean enteros o decimales; por ejm: let nombre = 10
- Boolean : es el que representa verdadero o falso y se utilza mucho en condicionales, por ejm: let nombre = true
- Bigint (numero grande) : es el que representa numeros enteros muy grandes que no caben en number, por ejm: let nombre = 1062143210340114230
- Null : es el que representa un valor vacio intencional, cuando el dato no tiene valor alguno, por ejm: let nombre = Null

condicionales

En el mundo de la programacion existen las condicionales. Las condicionales son estructuras de control que permiten tomar decisiones según si se cumple o no una condición. Es decir, hacen que tu programa pueda elegir qué hacer en cada situación.

Condicional if y else

¿Qué es? Es una estructura que permite tomar decisiones en el programa. 👉 Si se cumple una condición → hace algo 👉 Si NO se cumple → hace otra cosa, estructura:
if (condición) {
// lo que pasa si es verdadero
} else {
// lo que pasa si es falso
}

Condicional switch

¿Qué es? Se usa cuando tienes muchas opciones y no quieres usar muchos if, estructura:
switch (variable) {
case valor1:
// acción
break;

case valor2:
// acción
break;
default:
// si no coincide con ningún caso
}

Ciclo while

¿Qué es? Es un ciclo que se repite mientras una condición sea verdadera.

👉 Se usa cuando NO sabes cuántas veces se repetirá., estructura:
while (condición) {
// código que se repite
}
